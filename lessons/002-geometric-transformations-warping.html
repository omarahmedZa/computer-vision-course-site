Geometric Transformations & Image Warping

You can model 2D geometric deformations with transformation matrices and warp or restore images using forward vs inverse mapping with appropriate interpolation.

Why this matters

Cameras don’t see the world in a canonical pose: objects rotate, scale, skew, and project differently with viewpoint. Aligning scans, stitching panoramas, rectifying documents, augmenting data, and registering images all rely on moving pixels to new locations predictably.

Geometric vision asks two linked questions: what transformation maps coordinates? and how do we resample image intensities on a discrete grid? Getting either wrong produces holes, blur, or misalignment.

The one core idea

Represent 2D points in homogeneous coordinates so that translation, rotation, scale, shear, affine, and projective transforms become matrix multiplications. To produce an output image, prefer inverse warping: for each output pixel, find its source location and sample there with interpolation.

p' ~ H p,   p = [x, y, 1]^T

Warping an image = transforming coordinates + resampling intensities. Inverse mapping avoids holes; interpolation handles non-integer source positions.

How it actually works

1) 2D geometric transformations

Let a point be p=(x,y). Common transforms:

Translationt_x,t_yeverything (rigid shift)x'=x+t_x, y'=y+t_y
Rotationangle θlengths, angles (rigid)about origin: x'=x cosθ - y sinθ, y'=x sinθ + y cosθ

2) Homogeneous coordinates and matrices

Write p=[x,y,1]^T. A 2D affine transform is:

[x'; y'; 1] = [[a,b,t_x],[c,d,t_y],[0,0,1]] · [x; y; 1]

Translation becomes multiplication (crucial for composition). A homography uses a general 3×3 H with h_{31},h_{32} possibly nonzero and is defined up to scale:

x' = (h11 x + h12 y + h13)/(h31 x + h32 y + h33),   y' = (h21 x + h22 y + h23)/(h31 x + h32 y + h33)

Composition: apply A then B as p'' = B (A p) = (B A) p. Order matters (matrix multiplication is not commutative).

3) Forward vs inverse warping

To create output image I' from input I using mapping T:

  • Forward warping: for each source pixel p, compute p'=T(p) and copy intensity to I'(p'). Problem: p' may land between pixels (needs splatting) or multiple sources may map to same destination, and some destinations may receive nothing → holes.
  • Inverse warping: for each destination pixel p', compute source location p = T^{-1}(p') and sample I(p). Every destination pixel is visited exactly once (no holes), but requires interpolation because p is generally non-integer.

Standard practice: inverse warping + interpolation.

4) Interpolation (resampling)

When sampling at non-integer coordinates:

MethodHowTrade-off
Nearest neighborpick closest pixel valuefast, preserves values, blocky/aliasing
Bilinearlinear blend in x and y using 4 neighborssmoother, slight blur, common default
Bicubic (concept)fit using 16 neighborssharper/smoother than bilinear, more compute/ringing risk

Bilinear intuition: if (x,y) lies between integer grid points, interpolate horizontally along top and bottom, then vertically between those results (or vice versa) — weights proportional to distance.

5) Restoring geometrically deformed images

If an observed image is a warped version of an original (e.g. rotated/scaled/skewed scan), restoration means estimating the deformation and applying the appropriate inverse transform:

  1. Choose a motion model (translation/affine/homography) matching the distortion.
  2. Estimate parameters (from known calibration, correspondences, or other cues).
  3. Inverse-warp the deformed image onto a desired output grid with interpolation.

When correspondences are noisy or contain outliers, robust estimation (Lesson 5, used in Lesson 7) is essential.

Worked examples

Example 1 — Rotate a point (homogeneous matrix)

Rotate p=(2,1) by θ=90° counterclockwise about origin: cos90°=0, sin90°=1.

[x'; y'] = [[0,-1],[1,0]]·[2;1] = [-1; 2]

So (2,1) → (-1,2). With homogeneous coordinates, include translation in the same 3×3 multiply.

Example 2 — Composition order matters

Translate by (3,0) then rotate 90° vs rotate then translate:

  • p=(1,0): translate → (4,0), rotate → (0,4).
  • p=(1,0): rotate → (0,1), translate → (3,1).

Different results. The correct matrix is R·T for “translate then rotate” (applied right-to-left to the point).

Example 3 — Bilinear interpolation

Sample at (x,y)=(10.2, 20.7) with values I(10,20)=100, I(11,20)=120, I(10,21)=80, I(11,21)=110. Let dx=0.2, dy=0.7.

StepComputationValue
Top row100*(1-0.2)+120*0.2104
Bottom row80*0.8+110*0.286
Vertical104*(1-0.7)+86*0.791.4

Inverse warping computes this for every output pixel to fill the warped image smoothly.

The trap

Common pitfalls

Forward warping for image generation: sending source pixels to rounded destinations leaves gaps/overwrites — use inverse mapping for dense output images.

Coordinate conventions: image origin (top-left vs bottom-left), axis order (x,y) vs (row,col), and angle direction (degrees/radians, clockwise/counterclockwise) must be consistent.

“Bilinear is always best.” Nearest preserves categorical labels/exact values; bilinear/bicubic can blur edges or create non-original values. Choose based on the signal.

Ignoring inverse existence/scope: projective mappings can send points to infinity; always work within valid image bounds and handle invalid source samples.

Retrieval check

  1. Why do we use homogeneous coordinates for 2D transformations?
    Answer

    They let translation (and affine/projective transforms) be expressed as matrix multiplication, enabling easy composition and inversion using linear algebra.

  2. In inverse warping, for each output pixel you compute p = T^{-1}(p'). Why is interpolation usually required?
    Answer

    Because T^{-1}(p') generally falls at non-integer source coordinates; interpolation estimates intensity from nearby grid samples.

  3. If you apply a shear then a rotation, how should the combined matrix be formed relative to a point p?
    Answer

    As R·S·p (rotation matrix times shear matrix, applied right-to-left), so the shear acts first on p, then the rotation.

  4. Name one advantage of nearest-neighbor interpolation over bilinear.
    Answer

    It preserves original sample values (useful for labels/masks), is fast, and avoids introducing blurred intermediate intensities.
