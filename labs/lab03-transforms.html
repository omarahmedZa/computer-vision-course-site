Retrieval check


    
  
  1. Why can a 2×2 matrix not represent translation, but a 3×3 homogeneous matrix can?
    
    Answer
    A 2×2 linear map always sends the origin to the origin, so it cannot translate. Homogeneous coordinates add a constant column (and a third row/coordinate) so translation becomes a matrix multiplication.
    
  
    2. 
  
  2. If M = R·T is applied to point p as M p, which operation happens first?
    
    Answer
    Translation T happens first, then rotation R, because matrix multiplication applies right-to-left to the vector.
