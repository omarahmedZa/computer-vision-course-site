Convolutional features & receptive fields

You can see how stacked 3×3 convolutions respond to patterns and how receptive field size grows with depth.

Interactive demo

A simple 1D/2D intuition: select a stack depth (1–3 layers of 3×3, stride 1) and a learned-like filter pattern (edge/spot). We show the effective receptive field size and a toy response on a synthetic input.

Retrieval check

  1. If you stack two 3×3 convolutions with stride 1 (and no pooling), what is the receptive field size of an output unit relative to the input?
    Answer

    5×5. The first layer sees 3×3 of the input, and the second combines a 3×3 neighborhood of those, extending one pixel in each direction.

  2. Why do CNNs use weight sharing in convolutional layers for images?
    Answer

    It exploits the locality and (approximate) translation structure of images, greatly reducing parameters compared to dense connections and allowing the same pattern detector to respond anywhere in the image.
