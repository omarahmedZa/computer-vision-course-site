Retrieval check

  1. Why can a straight edge produce a low or negative Harris response even if gradient magnitude is high?
    Answer

    Because intensity changes mainly in one direction: one eigenvalue of the structure tensor is large but the other is small, so the cornerness term det(M) is small relative to k·trace(M)^2.

  2. What problem does non-maximum suppression solve after thresholding the response map?
    Answer

    Thresholding can mark many neighboring pixels around the same corner; NMS retains only local maxima so each detected corner is represented once and better localized.
