Lesson 01 — Introduction to Computer Vision

Vision pipeline · images as signals · pixels/channels · color spaces · histograms · intensity transforms · convolution

Core ideas

  • CV pipeline: acquire → preprocess → extract/compute → model/estimate → decide.
  • Image as signal: digital image = spatial sampling (resolution H×W) + value quantization (bit depth, e.g. 8-bit 0–255). Grayscale H×W, color H×W×C.
  • Channels/color: RGB (display), Grayscale/luma (≈0.299R+0.587G+0.114B), HSV (hue/saturation/value) separates color from brightness.
  • Histogram: frequency of intensities (global tone/contrast), no spatial info.
  • Point-wise transforms: g=T(I). Linear: g=αI+β (contrast/brightness, clamp). Gamma: g=c·I^γ on [0,1].

Convolution/filtering

  • Local weighted sum with kernel K: (I*K)(x,y)=ΣΣ I(x+i,y+j)K(i,j).
  • Correlation vs convolution: convolution flips kernel; same for symmetric kernels.
  • Kernels: box/Gaussian blur (smooth), sharpen (center-neighbor emphasis), Sobel/gradients (edges/changes).
  • Handle borders (padding), stride, and dtype/range (clipping/overflow).

Key formulas

I(x,y) or I(x,y,c) — image function/tensor
Y ≈ 0.299R + 0.587G + 0.114B
g = clip(αI + β), g = c·I^γ
(I*K)(x,y)=Σ_i Σ_j I(x+i,y+j)K(i,j)

Worked intuition

  • Box blur (1/9) preserves flat regions, pulls outliers toward neighbors.
  • Sharpen example: 5·center − sum(neighbors) boosts local contrast (clamp to range).
  • Asymmetric kernel: flip for convolution changes sign/orientation.

Pitfalls

  • RGB vs BGR/channel order; [0,1] vs [0,255]; gamma/encoding assumptions.
  • Overflow/wrap/saturation in 8-bit arithmetic.
  • Forgetting convolution flip for directional kernels.
  • Border padding and “histograms discard spatial layout”.
