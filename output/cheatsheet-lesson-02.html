Lesson 02 — Geometric Transformations & Image Warping

2D transforms · homogeneous matrices · forward vs inverse warping · interpolation · restoration

Core ideas

  • Homogeneous coords: p=[x,y,1]^T lets translation/affine/projective be matrix multiplies.
  • Transforms: translation, rotation, scale, shear (affine preserves parallel lines); projective/homography H (3×3, up to scale) preserves straight lines, models plane perspective.
  • Composition: apply A then B → (B·A)p; order matters.
  • Forward warping: send source pixels to destinations → holes/overwrites.
  • Inverse warping: for each destination pixel sample source at T^{-1}(p') → fills all outputs; needs interpolation.

Interpolation

  • Nearest: closest value (fast, preserves labels/values, blocky).
  • Bilinear: blend 4 neighbors (smooth, slight blur).
  • Bicubic (concept): 16 neighbors, smoother/sharper trade-offs.

Key formulas

p' = H p, p=[x,y,1]^T
Affine: [x';y';1]=[[a,b,tx],[c,d,ty],[0,0,1]][x;y;1]
Rotation: [[cosθ,-sinθ],[sinθ,cosθ]]
Homography (projective divide): x'=(h11x+h12y+h13)/(h31x+h32y+h33)
Alpha/bilinear: linear blend by distances (dx,dy)

Restoration pipeline

  • Choose motion model (translation/affine/homography).
  • Estimate parameters (correspondences/calibration).
  • Inverse-warp with interpolation onto output grid.

Pitfalls

  • Coordinate conventions (origin, x/y vs row/col), degrees vs radians.
  • Using forward warping for dense images (holes).
  • Wrong composition order; invalid/out-of-bounds source samples.
  • Bilinear can blur or create non-original values (bad for masks).
