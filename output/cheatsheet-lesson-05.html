Lesson 05 — Model Fitting (Hough Transform, RANSAC)

Hough voting · parameter space · lines/circles · RANSAC · inliers/outliers

Hough transform

  • Idea: each evidence point votes for all model parameters consistent with it; accumulator peaks = supported models.
  • Line (normal form): ρ = x cosθ + y sinθ. A point maps to a sinusoid in (θ,ρ); collinear points intersect at one peak.
  • Circles: (x−a)^2+(y−b)^2=r^2. Known r → 2D center votes; unknown r → 3D accumulator (costly).
  • Steps: edge points → vote in discretized accumulator → find peaks → recover models.

RANSAC

  • Repeat N times: sample minimal set (e.g. 2 for line, 4 for homography) → fit hypothesis → count inliers (error < τ) → keep best → refit on inliers.
  • Inlier ratio w, sample size s: P(good sample)=w^s, P(success in N)=1−(1−w^s)^N.

Key formulas

Line: ρ = x cosθ + y sinθ
RANSAC iterations: N ≥ log(1-p)/log(1-w^s)

When to use

  • Hough: detect parametric shapes (lines/circles) from edge evidence; robust to gaps/clutter but accumulator grows with params.
  • RANSAC: robust parameter estimation with outliers (fitting, registration, homography estimation).

Pitfalls

  • Accumulator resolution/range trade-offs; multiple structures need multiple peaks/runs.
  • RANSAC: τ too tight/loose, too few iterations, degenerate samples.
  • Dominant wrong structure if true inliers lack support.
