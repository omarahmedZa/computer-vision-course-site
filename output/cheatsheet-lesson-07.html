Lesson 07 — Image Registration

Alignment pipeline · feature matching · transform estimation · warping/resampling · similarity measures

End-to-end pipeline

  • 1) Detect features in both images (corners/blobs/keypoints).
  • 2) Describe & match (descriptor distance, ratio test) → tentative correspondences (with outliers).
  • 3) Choose motion model: translation/similarity/affine (6 dof, parallel lines preserved)/homography (8 dof, planar perspective).
  • 4) Estimate T robustly: RANSAC (sample minimal set → fit → count inliers → keep best → refit).
  • 5) Warp/resample: inverse warp moving image into target frame with interpolation.
  • 6) Evaluate: reprojection residuals, overlays/difference, or similarity metrics.

Similarity measures

  • SSD/SAD: intensity differences (sensitive to photometric change).
  • NCC: more robust to linear brightness/contrast shifts.
  • Mutual Information: statistical dependence, useful across modalities.

Key points

Affine: ≥3 point pairs. Homography (DLT): ≥4 pairs (planar/pure-rotation cases).
Inverse warping: sample source at T^{-1}(p') for every target pixel.

Failure modes

  • Too few/poorly distributed/wrong matches; weak texture or little overlap.
  • Wrong motion model (e.g. homography for non-planar parallax).
  • Photometric differences misleading intensity measures.
  • Out-of-bounds/poor interpolation artifacts.

Pitfalls

  • Never trust raw matches without robust estimation/geometric checks.
  • Good global score can hide local misalignment — inspect overlays/residuals.
